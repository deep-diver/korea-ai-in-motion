# 모바일 추가 개선 — 2차 10회

기준: c6e05b3. 기존 데스크톱의 배치·크기는 유지하고 모바일의 읽기와 조작을 개선한다.

| 회차 | 개선한 점 | 확인 |
|---|---|---|
| 1 | 현재 장면 해설을 무대 바로 아래로 이동하고 아래 본문의 중복 해설은 모바일에서 숨김 | 세로 화면에서 3D와 해설을 연속해서 볼 수 있음. 최대 두 개의 연결된 인물·오브젝트 카드는 유지 |
| 2 | 고정 재생 바에 현재 순서·장면 이름과 무대 복귀 링크 추가 | 본문을 읽다가 복귀해도 장면 제목이 고정 컨트롤에 가려지지 않음 |
| 3 | 근거 카드에 명시적인 읽기 일시정지·계속 재생 버튼 추가 | 실제 터치 후 0.9초간 시간이 멈추고, 재개 후 시간이 다시 흐르는 것을 확인 |
| 4 | 터치를 마우스 hover로 처리해 재생이 계속 멈추는 상황 방지 | touch 포인터는 hover 일시정지를 만들지 않으며 마우스와 키보드 동작은 유지. 토글에 포커스가 남아도 재개 가능 |
| 5 | 근거 알림과 미리보기가 같은 공간을 사용하도록 정리 | 알림 닫기 전후 슬롯 높이 일치. 미리보기에도 자료 종류와 원문 링크 제공 |
| 6 | 분과 변경 시 속도·일시정지 설정 보존 | 3×로 일시정지한 뒤 다른 분과로 가도 유지. 일시정지 분과의 첫 장면은 오브젝트가 등장한 시점으로 표시 |
| 7 | 선택한 분과 버튼이 가로 스크롤 영역 안에 남도록 보정 | 마지막 분과 선택 후에도 버튼 전체가 390px 화면 안에 보임. 페이지의 세로 위치는 이동시키지 않음 |
| 8 | 타임라인 제목을 모바일에서 두 줄까지 표시 | 전체 날짜·제목을 접근 가능한 이름으로 제공. 현재 장면의 대비와 테두리를 강화 |
| 9 | 인물 사진·직함·대사 구분의 가독성 개선 | 사진은 46×52px, 보조 설명은 13px와 더 밝은 색상 사용. 최대 두 카드 유지 |
| 10 | 터치 피드백·포커스 여백·가로 화면의 고정 바 높이와 복귀 여백 정리 | 작은 화면부터 가로 화면까지 오버플로 검사, 타임라인 키보드·무대 터치 입력 재검증 |

## 검증

- 320×740 / 390×844 / 768×1024 / 844×390: 문서의 가로 넘침과 런타임 오류 없음.
- 1440×1000 데스크톱 전후 전체 화면은 같은 크기이며 차이는 연결선 가장자리 1픽셀 범위.
- 실제 터치 입력: 읽기 일시정지·재개, 수직 스크롤, 다음, 속도, 타임라인 키보드.
- 대표 10개 장면의 카드 위치와 기존 모바일 조작 회귀 검사.
- 근거 자료 테스트에 touch/mouse 구분 및 포커스를 유지한 채 읽기 토글 재개 검증 추가.
- 로컬 증빙: `outputs/mobile-review/refine2-interactions.json`과 화면 캡처. 배포에는 포함하지 않음.
